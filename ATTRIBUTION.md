### How this differs from upstream (summary)

- Electron host replaced with **Go + Wails** for a single Windows executable  
- Optional **Setup** wizard (audit, install path, updates, dependency helpers)  
- Packaging and install paths tailored for Windows  
- Generative coding tools assisted the port and packaging
